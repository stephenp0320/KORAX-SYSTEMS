# Verification

Korax's decoder is validated against the ASTM F3411 / opendroneid wire format,
not against its own assumptions. This document records how.

## Method

The unit-test fixtures in `tests/unit/` are real ODID wire messages generated by
an **independent encoder** that follows the opendroneid encoding rules
(little-endian multi-byte fields, exact flag-bit packing, spec scaling). The
decoder is asserted against the *original field values* that were encoded, so a
passing suite means "Korax agrees with the wire format", not "Korax agrees with
itself".

Coverage: all six message types (Basic ID, Location, Auth, Self ID, System,
Operator ID), the Message Pack container, and the error paths.
